# Munder Difflin v0.4.5

**A local hive of Claude Code, Antigravity, Codex, Gemini, Cursor, Grok & Copilot agents that run themselves.**
Messaging, routing, and remembering, coordinated by your clone, Michael, who you talk to.

---

## What's new in 0.4.5

**Focus mode that survives a restart, terminals that follow the app theme, two new engines, and a
hive that wakes idle workers instead of letting mail pile up.** Plus the update notice itself now
says what restarting does, and gets out of the way when you click it.

- **Focus mode** (the thing we used to call fullscreen) comes back after a restart, survives
  closing an agent, refits when the roster changes, and its close button no longer drops you
  to the sidebar.
- **Terminals match the window.** The app answers the OSC colour queries, tells running TUIs
  when the theme flips, and hands Crush and OpenCode the theme at spawn so they stop rendering
  dark on light. A partial ANSI escape split across pty chunks no longer leaks into the text.
- **Gemini CLI and Cursor Agent** join the engine list.
- **Michael hires on his own terms.** Spawning is behind a setting, he picks a worker's avatar
  and accent, and agent names can be edited after spin up.
- **Hive.** God's roster shows each agent's live context occupancy, a watchdog wakes idle workers
  with undrained mail, mail to a missing inbox is bounced and logged instead of dropped, stale
  nudges stop, the steer queue is capped, registry writes are atomic, and PROTOCOL.md refreshes
  on boot so protocol changes reach existing hives.
- **Windows.** Agent processes no longer keep running after the app quits.
- **Updates.** Restart to update closes the notice first so the quit warning is never hidden
  behind it; installs that cannot self update get a direct download for their platform.
- **Founders' Wall** is automated from Razorpay: additions arrive as a PR, refunds are removed
  directly.
